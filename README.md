# car

**Kaze Festival** — an open-world, Horizon-style driving game in a single `index.html` (Three.js from CDN).

Open `index.html` in a browser (or serve the folder, e.g. `python3 -m http.server`).

Controls: `WASD`/arrows drive · `Space` handbrake · `Shift` boost · `C` camera · `T` time of day · `R` reset · `Esc` pause. Gamepad and touch supported.
