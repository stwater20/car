# car

**停好停滿 Park Formosa** — a hard, original parking game in the browser. Eight levels: the Taiwanese driving-test items (reverse bay parking, parallel parking, S-curve forward and in reverse), then a night-market street, a B3 garage and a townhouse garage. Touching a line or anything solid fails the level. Rear camera with guide lines, parking sensors, real wheel angles.

- `index.html` — the parking game (single file, Three.js from CDN, procedural car models and audio)
- `drive.html` — the earlier open-world mode (Hualien coast)
- `site/` — the searchable intro page; GitHub Pages serves it at `/`, the game at `/play/`, open world at `/drive/`

Controls: `W`/`S` drive and reverse · `A`/`D` steering wheel · `Space` brake · `C` camera · `R` retry · `Esc` pause. Phones: landscape, steering wheel on the left, pedals on the right.
