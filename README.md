# car

**Formosa Drive（花蓮公路行）** — an original open-world arcade driving game set on Taiwan's Hualien coast (花蓮): the city's row houses and night-market signs, Qixingtan beach, the Su-Hua cliff galleries at Qingshui and the Taroko Gorge arch. Single `index.html`, Three.js from CDN, procedural engine audio.

Open `index.html` in a browser (or serve the folder, e.g. `python3 -m http.server`).

Controls: `WASD`/arrows drive · `Space` handbrake · `Shift` boost · `C` camera · `T` time of day · `R` reset · `Esc` pause. Gamepad and touch supported.
